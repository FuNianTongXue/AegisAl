# SecFlow 产品功能文档

## 1. 产品定位

SecFlow 是面向安全分析师、研发人员和安全运营团队的本地优先安全智能体。产品把代码与依赖扫描、漏洞情报、组件查询、知识图谱、报告生成和日常安全资讯统一到原生 macOS 工作台中，并通过 LangGraph 展示任务步骤、工具调用和需要用户确认的关键动作。

当前智能体运行时采用 Multi-Agent Supervisor：由 Supervisor 理解开放式目标，再交接给 Project Context、Code Scan、Component Intelligence、SBOM、Vulnerability Intelligence、Report 或 Security Conversation Agent，最后由 Result Aggregator 统一输出。每个 Agent 使用独立能力和工具白名单，并保留可审计 handoff；这不是将普通 LangGraph 节点简单改名为 Agent。

当前版本为 1.2.0 内测版，最低支持 macOS 14.0。

## 2. 核心用户流程

### 2.1 上传项目并扫描

1. 在“新建任务”中选择本地项目目录并输入扫描目标。
2. 项目提交后写入当前用户长期项目记忆，保留项目名称、任务编号、目标和会话关联。
3. 系统只读检查工作区，识别语言、依赖清单、项目许可和支持范围。
4. 优先分析依赖和许可，再由逐语言节点通过独立 MCP SSE 服务执行静态规则和 AST/CFG/DFG/污点分析。
5. 系统融合证据；普通上传项目可生成仅对本任务生效的受限 Overlay，并最多重扫三轮。
6. 前端实时展示计划、LangGraph 节点、工具调用、发现数量和失败原因。
7. 扫描结束后，用户确认是否生成报告。
8. 报告完成后，用户再次确认是否下载，并选择 Markdown、HTML、Word、PDF 或全部格式。

### 2.2 在智能问答中查询

- 输入安全问题，获得结合本地知识、实时情报和长期上下文的回答。
- 上传受支持的源代码或依赖清单，对附件进行静态和语义分析。
- 输入组件名称和版本，自动进入组件查询子图，并生成表格和依赖到漏洞的 Sankey 数据。
- 发出生成、下载或批量下载报告的指令，自动进入报告子图并在人机中断点等待确认。
- 分析期间以真实 LangGraph 事件实时更新 Agent 时间线，展示运行、完成、警告和失败状态；不以预设假步骤代替后端执行。
- 智能问答可通过 `app.assistant_app:app` 独立部署，只包含问答、SSE、Interrupt、制品与会话能力，不携带扫描任务和订阅路由。
- 回答顶部显示 Security Agent、当前模型、工具/MCP 数量、耗时、模型返回的汇总 Token 数和知识命中；Thinking 只展示高层任务，不展示模型私有推理。供应商未返回 usage 时省略 Token 指标。
- Tool Call 和 Sources 默认折叠，可查看脱敏输入输出、公开来源名称与链接；凭证、内部集合、私有接口和完整请求载荷不进入客户端。
- 正文通过 SSE `content` 事件增量显示；支持 OpenAI Responses、OpenAI-compatible Chat 和 Anthropic 的真实文本 delta，确定性回答使用兼容分片，私有推理字段不会传输。等待时使用 Skeleton；完成后支持复制、重新生成、继续回答、导出、分享和收藏。
- Markdown 支持标题、列表、引用、表格、代码块、图片和基础 Mermaid 流程图，漏洞事实同时可用安全分析卡片呈现。
- 输入框提供 `/scan`、`/cve`、`/report`、`/code-review`、`@Security Agent` 和 `#漏洞知识库` 建议，并支持选择或拖入项目。

## 3. 功能清单

### 3.1 工作区与任务管理

| 功能 | 说明 |
| --- | --- |
| 可收缩导航 | 侧栏在悬停时平滑展开、移出后收回，主操作只保留“新建任务”，不改变当前任务 |
| 普通问答项目 | 历史问答统一归属侧栏“项目”下的“智能问答”项目；新建任务创建新会话，切换回来可恢复完整问答 |
| 对话归档与删除 | 对话行右键可归档、从统一归档区恢复，或在不可撤销确认后永久删除；删除后相关长期记忆同步重建 |
| 节点可见性 | 普通问答不展示内部 LangGraph 节点；代码扫描任务继续展示完整执行节点和审计状态 |
| Agent 交接 | 后端保存真实 Supervisor/专业 Agent handoff；客户端只展示适合用户理解的高层任务，不展示私有推理 |
| 评测隔离 | 在线 Agent 无权修改全局规则和引擎；项目自适应仅写任务级 Overlay，500 项目冻结评测独立运行 |
| 终态一致性 | 节点完成后折叠历史运行心跳；报告按钮和报告 API 必须同时通过 `report_ready` 门禁 |
| 项目选择 | 选择本机目录作为扫描工作区，不需要把源码上传到远程服务 |
| 完整上传扫描 | 普通上传读取全部受支持生产源码与清单，不使用 300 文件、500 KB 单文件或 6 MB 总读取上限 |
| 多语言识别 | 自动识别受支持语言、清单、构建系统和未支持文件 |
| 实时执行轨迹 | 通过 SSE 展示排队、运行、节点完成、警告、中断、失败和完成状态 |
| 独立任务 Worker | FastAPI 只写持久队列；独立 Python Worker 通过租约执行 LangGraph，崩溃后可恢复且不会提前开放报告 |
| 取消与重试 | 运行中可取消；失败、取消或中断后可恢复执行 |
| 归档与恢复 | 终止状态任务可归档，归档任务可恢复到任务列表 |
| 永久删除 | 二次确认后删除任务及其加密执行记录 |
| 任务隔离 | 每个任务有独立 ID、用户归属、计划、事件和结果 |
| 长期项目记忆 | 提交、重新扫描或生成项目 SBOM 时建立项目、会话、任务与制品关联；后续扫描意图先复验原源码目录，目录移动或匹配歧义时要求重新选择；不同用户不共享记录 |

### 3.2 代码与依赖安全扫描

| 能力 | 说明 |
| --- | --- |
| 依赖优先 | 优先解析 `go.mod`、Python requirements 等清单，再补充其他清单与源码引用 |
| 独立扫描 MCP | 普通用户扫描按需拉起仅绑定本机动态端口的 Code Scan MCP SSE 子进程，记录工具、PID、耗时和输入/输出哈希 |
| 项目许可识别 | 从 SPDX、结构化清单和许可证文件识别许可，并通过固定 OSI License API 标准化；接口失败时保留本地证据并标记部分覆盖 |
| 静态规则 | 按语言加载冻结 Semgrep 安全规则 |
| AST | 使用 Tree-sitter 解析语法结构并记录解析覆盖和错误 |
| CFG/DFG | 构建控制流和数据流证据，辅助确认跨语句风险 |
| 污点分析 | 识别 source、传播、sanitizer 和 sink 路径，报告可展示路径步骤 |
| 完整 Java 跨方法分析 | 普通上传取消 18 秒和方法数量保护，摘要传播到语义收敛；运行中仍可由用户取消 |
| 证据融合 | 合并规则命中、解析状态、CFG/DFG、污点候选和依赖证据 |
| 项目自适应 | 仅对普通上传项目生成受限 Overlay，最多三轮，失败回退基线 |
| 结果校验 | 汇总文件、语言、解析错误、主告警、复核候选和失败归因 |

扫描不会执行上传项目的构建脚本、测试、安装钩子或任意命令。动态引擎在当前产品语义中指运行时扫描/语义分析能力，不代表自动执行不可信项目。

### 3.3 500 项目可复现评测

- 使用固定的不同语言高星 GitHub 项目清单、提交和抽样信息。
- 构造可验证真值与裁决记录，保存样本清单、指标、失败归因和回归证据。
- 持续优化 Semgrep 规则、Tree-sitter 解析、CFG/DFG 和污点引擎。
- 目标门禁：评测集上观察到的漏报数为 0，precision/准确率至少 95%，并尽量降低误报率。
- 评测模式冻结规则与配置，不调用项目自适应模型，不接收普通上传任务 Overlay 的反馈写入，并保持原进程内引擎路径以隔离 MCP 传输变量。
- 评测继续使用原文件与时间保护配置，普通上传的完整扫描模式不会改变历史样本覆盖或指标口径。
- 评测结果属于工程质量证据，不等于对任意未知项目作出“绝对无漏报”的保证。

### 3.4 组件查询与漏洞情报

- 支持按组件名、版本和生态查询本地及实时漏洞。
- 支持自然语言表达当前月、上月、近 N 天、指定年月或日期范围的组件漏洞清单；LLM 选择能力，后端校验日期和筛选条件。
- 聚合 NVD、GitHub Advisory、OSV 等数据源，并保留来源和更新时间。
- 在智能问答内生成漏洞摘要、影响版本、严重性、修复建议和证据链接。
- 安全回答根据可核验事实选择漏洞摘要、影响范围、漏洞详情、利用条件、风险分析、修复建议和参考来源等章节；无事实或与问题无关的章节自动省略。
- 通过 Excel MCP 生成结构化表格制品，通过 D3 Sankey MCP 表达组件、依赖和漏洞关系。
- 目录查询先展示结果，再分别确认 Excel 生成和保存位置；Excel 使用固定查询结果并记录结果指纹，避免确认期间数据漂移。
- 支持按 CVE/GHSA 标识导出相关组件信息。

### 3.5 报告生成与下载

| 阶段 | 产品行为 |
| --- | --- |
| 生成前确认 | interrupt 展示动作、报告范围和风险，用户确认后才继续 |
| JSON 规范化 | 代码发现、依赖结果、指标、证据和失败归因转换为稳定 JSON |
| SARIF 污点事实 | SARIF MCP 用 2.1.0 `codeFlows/threadFlows/locations` 保留每个污点节点的顺序、角色、文件、行号、标签和代码片段 |
| Mermaid JPEG | Mermaid MCP 从 SARIF 逐条生成完整污点流程，长路径自动增长画布并输出可校验 JPEG，不截断节点 |
| 格式生成 | Markdown、Word、PDF 分别调用独立 MCP；HTML、Word、PDF 从 canonical JSON 嵌入同一 JPEG，保留换行、代码块和漏洞代码片段 |
| 格式审计 | 每个 MCP 记录输入/输出 SHA-256、MIME、大小、时间、渲染器和失败原因 |
| 下载前确认 | 第二个 interrupt 让用户确认下载以及单一或全部格式 |
| 报告管理 | 可查看详情、单份下载、全部格式下载、批量下载和删除 |

报告中心能力已收敛到智能体和设置中的日志/制品工作流，主导航不再显示独立“报告中心”。

### 3.6 项目 SBOM 与组件漏洞匹配

- 选择项目后可用自然语言要求软件物料、依赖资产、供应链组件清单或 SBOM Excel；LLM 根据目标、项目范围、产物和下载位置选择能力，不要求固定措辞。
- 依赖和项目许可事实先转换为 CycloneDX 兼容 JSON；依赖保留生态、名称、版本、PURL、来源清单、声明和置信度，项目许可保留 SPDX、识别方式、证据文件、OSI 状态和审计哈希。
- 第一次 interrupt 询问是否匹配组件漏洞情报；未解析版本不会被误报为“无漏洞”，而是在覆盖状态中单独计数。
- 第二次 interrupt 确认生成 Excel；SBOM Excel MCP 只消费固定 JSON，输出摘要、SBOM 组件、项目许可、漏洞匹配、来源与审计五张表。
- 第三次 interrupt 确认下载。用户指定“桌面”时，客户端通过 macOS 系统 API 定位当前账号的桌面目录，自动写入失败时回退原生保存面板。
- SBOM 工作流不修改静态规则、AST/CFG/DFG/污点引擎、项目 Overlay 或 500 项目冻结评测配置与指标。
- 许可识别用于工程盘点和审计提示，不构成法律意见；依赖组件许可仍需结合包仓库元数据或发布物复核。

### 3.7 实时信息咨询

- 以独立 `NSPanel` 固定在屏幕右上角，不占主导航。
- 登录后自动显示并轮询更新，也支持手动强制刷新。
- 刷新后以最新发布时间排序并更新当前内容，避免继续停留在旧条目。
- 支持订阅来源管理、批量启停、单源连通性测试和失败原因显示。
- 资讯无可用图片时使用来源或对应公司的 Logo 回退。
- 资讯类别、来源、时间和标题使用适合窄面板阅读的布局。

### 3.8 漏洞情报总览、知识图谱与日志

- 漏洞情报总览使用独立窗口展示情报目录中的漏洞、风险等级、趋势和发布日期范围，并明确排除代码扫描结果。
- 知识图谱展示漏洞、组件、依赖、代码文件与修复关系。
- 日志管理位于设置模块，集中展示采集、问答、任务和报告记录。
- 采集器支持 CVE 与 GitHub Advisory 配置、连接测试、手动采集和运行状态。

### 3.9 模型配置

- 登录后设置采用 6 步向导：用户资料、角色、模型厂商、具体模型、连接信息、验证完成。
- 新账号从资料开始；资料已完成但模型缺失时从模型厂商继续；资料和模型都有效的已有账号直接进入工作区。
- 昵称、部门和角色保存成功后才能进入模型步骤；模型连接测试成功后才能加密保存并启用。
- 登录账号由当前登录信息带入且不可在向导中修改，退出或切换账号会清空未保存的向导草稿。
- 支持 OpenAI、Anthropic Claude、DeepSeek 和 OpenAI 兼容自定义端点。
- 模型下拉框优先通过各提供商官方模型 API 拉取，失败时使用内置目录和手工模型名。
- 可配置端点、API Key、最大 Token、temperature、top_p、超时、wire API 和推理强度。
- 保存前可测试连接；界面不会回显完整 API Key。

### 3.10 设置、订阅与本地化

- 用户资料：昵称、邮箱、手机、部门、岗位、工号、简介和头像。
- 订阅管理：套餐、支付方式、用量、订单、自动续费取消和支付事件。
- 通用设置：简体/繁体中文、英语、日语、韩语、西班牙语、法语、德语、意大利语和俄语，以及字号、开机启动和更新检查。
- 关于与协议：版本、发布渠道、服务协议和隐私政策。
- 字体：中文 PingFang SC，英文 SF Pro Text，Emoji 使用 Apple Color Emoji 系统回退。

| 角色 | 典型场景 |
| --- | --- |
| 安全分析师 | 上传项目、复核污点路径、追踪误报/漏报、输出审计报告 |

## 5. 数据输入与输出

输入：

- 本地工作区绝对路径。
- 问答文本、受支持的源代码附件和依赖清单。
- 组件坐标、漏洞标识、日期范围和资讯来源配置。
- 模型、采集器和订阅配置。

输出：

- 任务计划、节点事件、扫描 JSON、代码/依赖发现和失败归因。
- 对话回答、漏洞卡片、知识图谱、Excel 和 Sankey 制品。
- Markdown、HTML、Word、PDF 报告和对应图表数据。
- 500 项目评测样本、真值、指标与回归门禁结果。

## 6. 非功能要求与限制

- 本地优先：桌面后端默认只绑定回环地址，项目源码不应被隐式上传。
- 可审计：任务、模型工具调用、报告确认、评测配置和结果均保留结构化证据。
- 可恢复：SSE 支持事件序号续传，任务队列使用租约、心跳和最多三次 Worker 崩溃恢复；任务支持取消、重试、归档，普通问答切换后可从本地持久化记录恢复。
- 隐私：敏感配置加密保存，公开回答和日志执行隐私清洗。
- 可复现：评测固定项目、提交、规则和真值版本；交付包提供源码快照来源和 SHA-256 清单。
- 当前限制：API 缺少完整远程多用户鉴权；拉取请求、已安排和插件尚未完成外部服务接入；静态/语义扫描不能替代运行时渗透测试和人工复核。

## 7. 验收重点

- 普通用户能够选择项目、启动扫描、看到实时节点、取消/重试并读取结果。
- 生成报告前和下载报告前的 interrupt 均可确认或取消，恢复后状态一致。
- 报告代码片段保留换行和等宽排版；SARIF、Mermaid 和 JPEG 节点数一致，HTML/PDF/Word 不截断标题、表格和污点路径。
- 手动刷新资讯后显示最新条目；失败订阅给出可定位原因；缺图条目使用来源/公司 Logo。
- 扫描任务与普通问答均归属于项目；两者均支持右键归档、恢复和永久删除，导航保持可收缩且不再出现组件查询和报告中心独立入口。
- 上传项目 Overlay 不影响 500 项目冻结评测；评测门禁可独立重复执行。

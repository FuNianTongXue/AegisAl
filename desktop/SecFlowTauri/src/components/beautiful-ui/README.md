# Beautiful UI adapters

This directory adapts the AI-native interaction patterns from
[Beautiful UI](https://www.beautifului.dev/) to AegisAl's React/Tauri design
tokens. The components contain no demo content, external runtime dependency,
remote asset request, or product branding.

- `BeautifulLoadingState`: pixel-grid loading and elapsed-time state.
- `BeautifulThinkingTrigger`: expandable agent reasoning summary.
- `BeautifulToolChipTrigger`: compact live tool-call state.
- `BeautifulTaskRow`: task status row with a live state rail.
- `BeautifulApprovalCard`: human-in-the-loop confirmation surface.
- `BeautifulEmptyState`: search and filtering empty state.

The upstream patterns are MIT licensed. The bundled notice is at
`licenses/Beautiful-UI-MIT.txt`.
